Mis proyectos

AWS · CLOUD SECURITY

AWS Secure Web Portfolio

Implementación de un sitio web estático utilizando Amazon S3 como origen privado y Amazon CloudFront para distribuir el contenido mediante HTTPS.

Se utiliza Origin Access Control (OAC) para autorizar el acceso de CloudFront al bucket y mantener restringido el acceso público directo a los objetos de S3.

  • Bloqueo de acceso público en Amazon S3.
  • Acceso al sitio mediante HTTPS.
  • Validación de acceso directo a S3: 403 AccessDenied.
  • Revisión de permisos y configuración de acceso.

Estado: implementación y validación inicial realizadas.
